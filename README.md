## 🚀 INSTALLATION & EXECUTION

### Requirements

- Modern WebGL-compatible browser
- Python 3 (for modular development)
- Internet connection on first load for the Three.js CDN dependency

### Option 1 — Quick Launch

Open the following file directly in your browser:

```text
dist/index.html
```

The distribution build is a single self-contained HTML file.

### Option 2 — Run Modular Source

Navigate to the source directory:

```bash
cd src
```

Start a local development server:

```bash
python3 -m http.server 8080
```

Open your browser:

```text
http://localhost:8080
```

### Rebuild the Project

After modifying the source files, regenerate the HTML builds:

```bash
python3 tools/build.py
```
